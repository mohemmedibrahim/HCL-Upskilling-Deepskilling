
# Frontend Development Projects 

This repository contains frontend development projects created as part of my HCL training. These projects demonstrate my practical knowledge of HTML, CSS, JavaScript, responsive web design, and interactive web applications.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (where applicable)

## Projects

### 1. Form Creation

Created a user registration form with personal information fields.

**Features:**
- Name, age, gender, address, phone number, and email fields
- Clean form layout
- Organized input fields

### 2. Website Clone

Developed a clone of an existing website to practise frontend development and website layout design.

**Features:**
- Website layout recreation
- CSS styling
- Responsive design (where implemented)

### 3. Personal Portfolio

Developed a personal portfolio website to showcase my profile and technical skills.

**Features:**
- Personal introduction
- Technical skills
- Projects and achievements
- Contact information

### 4. BMI Calculator

Built a BMI calculator using HTML, CSS, and JavaScript.

**Features:**
- Height and weight input
- Automatic BMI calculation
- Result display
- Input validation

### 5. Bill Generator

Created a billing application for calculating product prices and generating bills.

**Features:**
- Product selection
- Quantity-based calculations
- Automatic total calculation
- Bill generation

### 6. Student Management System

Developed a frontend application to manage student records.

**Features:**
- Add student details
- View student records
- Display records in a table
- Delete student records
- JavaScript-based functionality

### 7. Bakery and Cake Shop Website

Developed a bakery website to display bakery products and cakes using HTML, CSS, and Bootstrap.

**Features:**
- Home and About sections
- Bakery product listings
- Cake product cards with images
- Contact page
- Enquiry form
- Responsive navigation and layouts

## Learning Outcomes

- Gained practical experience in frontend development.
- Improved HTML, CSS, and JavaScript skills.
- Practised DOM manipulation and event handling.
- Learned to design responsive web pages using Bootstrap.
- Developed interactive forms and web applications.
- Improved debugging and problem-solving skills.
